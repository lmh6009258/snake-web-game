# Snake Web Game

이 프로젝트는 간단한 HTML/JavaScript 기반의 Snake(스네이크) 게임입니다.

- **제작:** helpy chat, githubmcp를 활용하여 자동화된 방식으로 개발되었습니다.
- **플레이 방법:**
  - 방향키로 뱀을 조작하여 사과를 먹으세요.
  - 벽이나 자기 몸에 부딪히면 게임이 종료됩니다.
  - [재시작] 버튼으로 게임을 다시 시작할 수 있습니다.
  - [속도 -], [속도 +] 버튼으로 게임 속도를 조절할 수 있습니다.

## 실행 방법

1. 이 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 웹 브라우저에서 열면 바로 게임을 플레이할 수 있습니다.

## GitHub Pages로 배포하는 방법

1. GitHub 저장소의 Settings(설정)으로 이동합니다.
2. 왼쪽 메뉴에서 "Pages"를 클릭합니다.
3. "Source"에서 `main` 브랜치와 `/ (root)` 디렉토리를 선택합니다.
4. 저장하면, 잠시 후 상단에 배포된 주소(예: https://lmh6009258.github.io/snake-web-game/)가 표시됩니다.
5. 해당 주소로 접속하면 웹에서 바로 게임을 즐길 수 있습니다.
